## Ver.1.0.4 修正内容
- Safariとホーム画面起動で上部バナーが同じ大きさになるよう、初回・2回目の表示差を廃止
- 日付詳細に「前の日」「次の日」を追加
- 8月31日→9月1日など、月をまたいで詳細画面のまま移動可能
- 日付移動前に入力中のメモを自動保存
- 月をまたいだ場合、背面のカレンダーも移動先の月へ切替
- 対象期間の最初・最後の日では移動ボタンを無効化
- タイトル表記を「沖縄手帳＋ 2026」に統一
- CSS・JavaScriptのキャッシュ更新用に Ver.1.0.4 を付与
