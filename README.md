## 収録期間
2026年8月〜2027年3月（8か月）

## 前版からの修正
- 表紙・ブラウザタイトル・ブランド表記を「2026」に固定
- 2027年1月、2月、3月を含む8か月の読込を起動時に検査
- CSS、データ、JavaScriptのファイル名を変更し、旧キャッシュを回避
- 過去の試作版で登録されたService WorkerとCache Storageを解除
- メモのlocalStorageは削除しないため、既存メモは保持

## GitHubへの反映

古い script.js / data.js / style.css が残っていても参照されませんが、混乱防止のため削除推奨です。
